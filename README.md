# eo-nature-damage

Estimating how nature responds to climate change from Earth observation and
other geospatial data, and using these estimates as empirical nature damage
functions in cost-benefit integrated assessment models.

## Idea

Cost-benefit integrated assessment models (for example DICE-type models)
describe how warming reduces the stock or value of nature with a damage
function. The parameters of these functions are usually set from expert
estimates or simulations. This project estimates such a relationship from
observed, spatially explicit data instead:

1. **Driver:** temperature change, with land use as a control
2. **Nature state:** an observed indicator of ecosystems over time and space
3. **Damage function:** loss of the indicator per degree of warming
4. **Integration:** use the estimated parameter in an integrated assessment
   model and compare the results with the default calibration
